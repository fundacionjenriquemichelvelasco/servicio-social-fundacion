# 🎓 Sistema de Gestión de Servicio Social - Fundación Enrique Michel Velasco

Sistema web integral desplegado en la nube para la administración, registro de estudiantes, pase de lista con evidencia fotográfica y control de entregables/investigaciones de servicio social.

---

##   Tecnologías Utilizadas

- **Frontend / Interfaz:** [Streamlit](https://streamlit.io/)
- **Base de Datos y Almacenamiento:** [Supabase](https://supabase.com/) (PostgreSQL & Cloud Storage)
- **Lenguaje Principal:** Python 3.10+
